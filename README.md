# EduCatch
Missed Class Information System and Academic Catch-Up System

**Project Description** -
A console-based Java application that serves as a centralized platform where students can easily access information about classes they missed. Class recorders can post lessons, topics, activities, assignments, deadlines, and announcements, while students can view all these details anytime — making it easier to catch up on missed academic responsibilities.

**Problem Being Addressed** -
Students who miss classes often struggle to find out what lessons were discussed, what activities or assignments were given, and what deadlines they need to meet. They usually rely on asking classmates individually, which is time-consuming and may result in incomplete or incorrect information.

**Project Objectives**
1. Provide a centralized, easy-to-access platform for missed class information
2. Ensure students get accurate and complete details about lessons, assignments, and deadlines
3. Reduce the time and effort spent chasing classmates for updates
4. Allow class recorders to efficiently post and manage class information
5. Demonstrate core Object-Oriented Programming (OOP) concepts in a practical application

**Target Users**
1. Students — to view missed class details, assignments, and announcements
2. Class Recorders — to upload, edit, and manage class information

Main Features

**For Students**
1. View a list of all recorded missed classes
2. Filter classes by subject and date
3. View lessons and topics discussed
4. Check activities and assignments
5. View assignment deadlines
6. Read important notes and announcements

**For Class Recorders**
1. Select and record the date of the missed class
2. Specify the subject
3. Add lessons and topics discussed
4. Upload activities and assignments
5. Set and update assignment deadlines
6. Add important notes and announcements
7. Edit or update previously posted information

**OOP Concepts Demonstrated**
1. **Classes & Objects** - Created classes such as MissedClass, Lesson, Assignment, User — instantiated objects to store and manage data 
2. **Encapsulation** - Used private instance variables with public getter and setter methods to protect data integrity 
3. **Inheritance** - Created a base User class with Student and ClassRecorder subclasses that inherit and extend its properties 
4. **Abstraction** - Simplified complex operations — users interact through clear menu options without needing to know how data is stored or retrieved 
5. **Arrays / Collections** - Used ArrayList to dynamically store and manage lists of missed class records 
6. **File I/O** - Used Java file handling to save and load records between program sessions
